# Автоматизация тестирования сайта пиццерии (тестовый стенд)
Скрипты проверяют функционал сайта пиццерии в порядке, основанном на нескольких пользовательских флоу (подробная информация в тест-кейсах).

Final_Practice использует Pytest (Selenium), а Final_Practice_promo_3 Playwright.

Проект поддерживает flake8, Allure и логирование

## Использование
Используется с окружением miniconda

Перед работой необходимо выполнить команды установки зависимостей, если они не установлены
```typescript
conda env update -f environment.yml

conda activate python-autotests-basic
```
